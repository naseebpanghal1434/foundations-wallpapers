Title: use class title-accent on the last phrase (usually the second sentence). Keep the visible title identical to catalog title.
Ghost number: unpadded (101 not 0101). Plate-id: "Plate 101 / 200".
Kicker left word is always DSA. Whisper is short uppercase-friendly (the CSS already uppercases).

Layout classes you MAY use (already in poster.css). Do not invent classes.
- compare / compare-pane / compare-pane--hit / compare-vs / pane-label / pane-title
- trio / box / box--pool / box-title / col-label
- grid4 / hops / hop / hop--here / hop-n / hop-name / hop-copy
- steps / step / step--hit / step-n / step-copy / step-meta
- codeblock  (add class "ok" when that pane is the good pattern)
- caption / bullets / rows / row / row--read / chips / chip
- pipeline only if it fits; prefer compare, trio, steps, grid4
Use stage--wide for trio and grid4.

HTML: escape < > & in code as &lt; &gt; &amp;. Use <code> for identifiers. Use <em> sparingly.

Voice: punchy, accurate, wallpaper-distance. Like plates 49–64. Concrete numbers and a worked example in the diagram. Name the interview problem. Cross-ref older plates as "plate 51" not links.

Accuracy over slogans. If a complexity is average, say average. Include the standard trap.

Density: lede 2–4 sentences. What/Why/Trap each 2–4 sentences. Diagram must teach, not decorate.

Do not wrap lines in codeblocks with extra indent that will show. Keep codeblock text left-aligned.

Existing plates 49–64 are overviews (Big O, array vs list, hashmap, stack/queue, binary search, two pointers, sliding window, recursion, traversals, BST vs heap, BFS/DFS, graphs, DP, trie, heaps, sorting). Wave 2 goes deeper with examples and named problems. Do not copy their titles. Overlap of topic is OK if the example is new.
