Frontendimport · require

ESM is static. CJS is now.

import/export is hoisted and statically analyzable — tree-shaking, circular bindings as live views. require is a function you call whenever; the value is a snapshot of module.exports at that line.

graph known before run

ESM live

import { x, inc } from './a.js' inc() x // 2 — live binding

a.js increments x; importers see the new x. Not a copy.

vs

value at this line

CJS snapshot

if (flag) { const { x } = require('./a') } // graph depends on runtime

Destructure is a copy. Later exports.x++ is invisible here.

What

Static graph vs dynamic load. import() is the async escape hatch (returns a Promise). Node: .mjs / "type":"module" vs .cjs.

Why

“Why can’t I require an ESM package?” Dual packages, or import(). Circular deps behave differently.

Trap

Destructure CJS and expect live updates. Mixing default export interop (module.exports = fn vs export default). Circular ESM that reads a binding before init (TDZ).
