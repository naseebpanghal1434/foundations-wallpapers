NetworkTLS 1.3 · 1-RTT · AES-GCM

Cert, keys, then encrypted HTTP.

TLS sits between TCP and HTTP (plate 01). TLS 1.3 is 1-RTT: ClientHello with a key share, ServerHello + certificate + Finished, then application data (TLS 1.2 is 2-RTT). The server proves identity with an X.509 chain (SAN, expiry, trusted CA). Bulk cipher is AES-GCM or ChaCha20-Poly1305. SNI is plaintext unless ECH.

What

Handshake, then records. Client verifies SAN + expiry + chain. Key exchange is usually ECDHE; the cert’s RSA/ECDSA key signs, it does not encrypt the HTTP.

Why

Without it, anyone on the path reads the cookie. A cert warning is this hop, not your Express handler (plate 13). Interviews: order the steps, say what is still visible.

Trap

Expired cert (forgot renew, or the box’s clock is wrong). Assuming HTTPS hides the hostname — SNI is still in the ClientHello. The server ignored SNI and served the default cert.
