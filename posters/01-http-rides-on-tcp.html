NetworkL7 on L4 · 80 / 443

HTTP rides on TCP.

HTTP (RFC 9110) is methods, headers, status, body. TCP (RFC 9293) is SOCK_STREAM: connect, sequence numbers, ACKs, retransmit. HTTP/1.1 and HTTP/2 use TCP; HTTP/3 keeps the same HTTP on QUIC/UDP 443 (plate 275).

TCP

1 RTT

SYN, SYN-ACK, ACK. ~20 ms metro, 80–150 ms US/EU

TLS 1.3

+1 RTT

Port 443. 0-RTT resume is replayable (plate 279)

HTTP/1.1

one req

Per fd until the response ends. 80 or 443

HTTP/2

streams

Many streams, one TCP. HOL is still TCP (plate 274)

HTTP/3

UDP 443

Same GET/200. Transport is QUIC, not TCP

socket() → connect() // 1 RTT handshake write(fd, "GET /api HTTP/1.1\r\nHost: api.shop.io\r\n\r\n") read(fd) → 200 / 404 / 500 // HTTP parses; TCP only delivered bytes
What

HTTP parses methods and status. TCP is connect/send/recv/close on a sequenced stream. Layers, not alternatives.

Why

ECONNREFUSED is TCP. Cert alert is TLS. 503 is HTTP. Naming the layer is the debug (plate 13).

Trap

Picking “TCP or HTTP.” HTTP/3 is still HTTP — only the transport is QUIC. Blocking UDP/443 forces a fallback to HTTP/2.
