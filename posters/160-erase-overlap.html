What

Classic greedy activity selection. O(n log n). Touching endpoints: usually allowed (non-overlapping). Contrast merge: there, next.start ≤ cur.end glues; here, start ≥ lastEnd keeps.

Why

LeetCode 435 / 452. If they ask max meetings in one room, this is it. Minimum removals is just n minus that set.

Trap

Sorting by start and keeping the longer. DP O(n²) when greedy is enough. Treating touching as overlap against the spec. Sorting by end and then still comparing the wrong bound.
