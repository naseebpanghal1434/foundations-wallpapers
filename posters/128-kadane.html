DSAMax subarray

Best ending here, or start over.

Kadane: walk left to right. At i, the best subarray ending at i is either a[i] alone or a[i] glued to the best ending at i−1. cur = max(a[i], cur+a[i]); ans = max(ans, cur). One pass, O(n), O(1) extra. The empty subarray is a policy: usually not allowed if the problem wants at least one element.

Reset when a[i] beats cur+a[i]. Store start=i on a reset if you need the bounds.

Init ans to a[0] (or −∞), never 0, unless the spec says empty is 0. Non-contiguous is a different problem.

What

Optimal substructure on “best ending at i.” DP with two variables. cur = max(a[i], cur+a[i]). Recover the window by noting the index where you last started over. Contiguous — adjacent cells.

Why

Maximum subarray (LeetCode 53). Maximum circular: Kadane plus total − min-subarray (and still the all-negative guard). If they say contiguous, think Kadane before n².

Trap

Initializing ans=0 so an all-negative array answers 0. “Max subsequence” — that sums the positives, not Kadane. 2D max rectangle is Kadane on compressed rows, not one line.
