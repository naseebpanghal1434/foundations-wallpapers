DSABST walk or recurse both

Split? This node. Else walk that side.

LCA is the deepest node that has both in its subtree — or is one of them. BST: walk until they split. General tree: recurse both sides; two non-nulls means this node.

Order is the map · O(h)

BST walk

6 / \ 2 8 / \ 0 4 p=2 q=8 both split at 6 p=2 q=4 6: both < → left 2 is p → 2

A node can be an ancestor of itself. Walk until the split — no extra storage.

or

No BST · O(n)

Recurse both

if node is p or q return node L = dfs(left) R = dfs(right) if L and R: this else: L or R parent pointers: walk up with a set

Post-order. Both sides non-null → this node. Assumes p and q exist in the tree.

What

BST O(h): paths diverge at the LCA. General O(n): return the node, not a boolean. A node may be an ancestor of itself.

Why

LeetCode 235 / 236. They switch BST vs binary. Say which property you used.

Trap

BST walk on a non-BST. Returning true/false. Missing the “node is p or q” base case.
