DSAAdjacent pairs · topo

Letters have order. That's a graph.

Alien dictionary: sorted words in an unknown alphabet. Compare consecutive words; the first differing letters give an edge earlier→later. If a longer word comes first and the next word is a prefix of it, invalid. Then topo sort the letters (Kahn). Unique order vs any order: if more than one letter has indegree 0 at a step, the order is not unique (return any, or '' if they demand unique).

topo
What

Build a directed graph of letter constraints from consecutive word pairs, then plate 176. O(total chars). An edge is the first difference only — later letters in that pair are not extra edges. Isolated letters still belong in the answer.

Why

LeetCode 269 (premium) / lintcode. Hard combo of string + topo. SDE-2 favorite. If they say “ordering with dependencies,” you already named topological sort before touching letters.

Trap

Comparing every pair of words, not consecutive (still correct, extra work, more prefix bugs). Edge on the second difference. Dropping letters that never differed. Treating the problem as sort-the-words. Missing the longer-then-prefix invalid case.
