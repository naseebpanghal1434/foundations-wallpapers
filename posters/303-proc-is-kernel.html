/proc is the kernel exported as files.

procfs is not disk. cat /proc/meminfo reads kernel structs. /proc/self/status: VmRSS, Threads, NSpid. /proc/net/tcp: sockets. /proc/sys: tunables (many also sysctl). Parsing these is the API for a lot of observability.
