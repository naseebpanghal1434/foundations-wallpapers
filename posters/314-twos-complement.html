Archtwo's complement · wrap

-1 is all bits set.

Signed integers: -x is ~x+1. 8-bit: -1 = 0xFF, -128 = 0x80. Addition is the same circuit as unsigned; overflow wraps mod 2^n in hardware. C signed overflow is UB (plate 327); unsigned wrap is defined. Java and Go wrap signed too.
