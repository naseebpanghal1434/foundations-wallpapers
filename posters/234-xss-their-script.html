FrontendinnerHTML · sanitize

XSS is their script on your origin.

XSS: attacker text is parsed as HTML/JS on your origin — then it is your cookies, storage, and session (plate 9). Treat untrusted strings as text (textContent, encode on the way out); CSP is the net.

parsed as HTML

innerHTML

el.innerHTML = comment // comment is // <img onerror=steal()> href={'javascript:…'} dangerouslySetInnerHTML

React JSX texts by default. The hole is dangerouslySetInnerHTML and a javascript URL.

vs

untrusted = text

textContent

el.textContent = comment // tags show as text sanitizer that drops script / on*

Encode on the way out. CSP script-src + nonce makes injected tags inert if you were sloppy elsewhere.

What

Stored, reflected, DOM-based — same payload class. CSP is a net, not a license to concatenate HTML.

Why

Frontend security interview #1. Pair with HttpOnly (plate 232) so residual XSS cannot lift the session cookie.

Trap

Sanitize on input, render with innerHTML later after a “safe” markdown path. Blacklisting <script> and missing onerror. Trusting JSON in a <script> tag without escaping <.
