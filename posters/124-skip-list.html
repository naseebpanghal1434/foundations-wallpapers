Express lanes over a list.

A skip list is a sorted linked list with extra forward pointers at coarser levels. Search starts on the top lane, drops when the next hop would pass the key. Expected height log n if each node joins the next level with p=1/2. Redis zset uses this.

expected log n

Expected O(log n) search / insert / delete. Level 0 is a full sorted scan for ranges.

What

Probabilistic alternative to a balanced BST (plate 113). Simpler to picture than rotations. Ordered, range scan along level 0. Not a hashmap — no O(1).

Why

Interview: “how does Redis sorted set work?” Skip list + hash. Also: why a list can still be log n if you add lanes. Same order ops as a TreeMap (plate 125).

Trap

Deterministic “every 2nd node” rebuild is a different structure (perfect skip) and painful to update. Worst case all height 1 if the coin hates you — expected, not worst-case like AVL. Not a replacement for a hashmap.
