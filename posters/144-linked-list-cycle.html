If they meet, there is a cycle.

Cycle detection without extra memory: slow walks one, fast walks two. If there is a cycle, fast laps slow and they meet. If fast hits null, no cycle. Meeting does not give the start — that’s plate 147. A set of seen nodes is O(n) space and also correct; they often want O(1) space.

What

Floyd. Time O(n), space O(1). Proof sketch: once both are in the cycle, relative speed 1 means they close the cycle length. A hashmap of nodes is the O(n)-space backup — say it, then write the two pointers.

Why

LeetCode 141. Also: cycle in a functional graph (happy number, duplicate in 1..n). Interviews want O(1) space. Draw the loop and two dots before the while.

Trap

fast = fast.next.next without a null guard. Treating the meeting node as the cycle start (plate 147). Starting slow at head and fast at head.next without matching the loop test — both placements work if the condition matches. Using a set after they asked O(1) space.
