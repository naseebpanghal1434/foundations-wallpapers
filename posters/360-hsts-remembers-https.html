BackendStrict-Transport-Security · preload

HSTS remembers HTTPS. The first HTTP visit is still open.

Strict-Transport-Security: max-age=31536000; includeSubDomains; preload. After one HTTPS response, the browser will not speak HTTP to that host for max-age. Preload bakes it into Chrome; the first visit (or a captive portal) can still be MITM without preload.

What

A browser pin to TLS. Server-side HTTPS-only is not the same as HSTS — the redirect itself is strippable.

Why

SSL stripping. Why preload exists for banks. max-age is seconds; 31536000 is a year.
