Backendtiming · hmac.compare_digest

memcmp returns early. Secrets must not.

memcmp / == on bytes stops at the first difference: an attacker times the response to learn the secret prefix. Use a constant-time compare (CRYPTO_memcmp, hmac.compare_digest, crypto.timingSafeEqual). Apply to tokens, CSRF, webhook signatures — not to “admin” vs “user” usernames.

What

Data-independent time for equal-length secret compares. Lengths should be public or padded.

Why

API keys, reset tokens, HMAC headers. A local attacker with a high-resolution clock reads prefixes.

Trap

hash_equals then a second ==. Comparing hashes with != in a high-resolution local attack. SHA256(password) without a KDF (plate 354).
