DSABIT · +i&-i

The index holds a prefix of bits.

A Fenwick tree (BIT) is a prefix-sum machine in an array of size n+1. Index i is responsible for a range whose length is the last set bit of i. add(i,δ): while i≤n, t[i]+=δ, i += i & −i. prefix(i): while i>0, s+=t[i], i -= i & −i. Both O(log n).

1

1-based. Never index 0i=6 = 110b, last bit 2, t[6] covers two cells. i=8 = 1000b covers eight.

last set bit
2

Update +2 at index 3Walk 3, 4, 8. Each step i += i & -i. Stop when i > n.

3

Range [l, r] is two prefixesprefix(r) − prefix(l-1). Query walks i -= i & -i down to 0.

query

i & -i isolates the lowest set bit (two’s complement). i += i & -i on 0 is 0 — infinite loop.

What

Point add + prefix query, or (via difference) range add + point query. Less general than a segment tree: the op needs an inverse (sum yes, min no). Size n+1, indices 1…n.

Why

Count inversions (map values, add 1 as you scan). Frequency of ranks. Interview: “range sum with updates” — Fenwick if it is prefix-shaped, segment if min/gcd (plate 120).

Trap

0-based loops that never move (i += i & -i on 0 stays 0). Using Fenwick for range minimum. Off-by-one: prefix(r) − prefix(l-1), not prefix(r) − prefix(l).
