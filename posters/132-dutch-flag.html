DSASort colors · 0 1 2

Three pointers. Three colors.

Dutch national flag: partition an array of three values (0, 1, 2) in one pass. lo writes the next 0, hi writes the next 2, mid scans. Meet a 0: swap with lo++, mid++. Meet a 2: swap with hi--, do not mid++ (the new mid is unseen). Meet a 1: mid++.

One pass · three regions

0 / 1 / 2

[2,0,2,1,1,0] [0,lo) 0s [lo,mid) 1s [mid,hi] unknown (hi,n) 2s 0: swap with lo, lo++ mid++ 1: mid++ 2: swap with hi, hi-- # stay

Stop when mid > hi. Also the 3-way partition inside quicksort for duplicates (plate 163).

trap

The swapped-in value is unseen

No mid++

swap a[mid], a[hi] hi -= 1 mid += 1 # bug you just pulled an unknown into mid — 0 or 2 skip it and the invariant dies [2,0,…] swap with last 0 mid++ would skip that 0

A 0 swapped from hi still needs a lo-swap. Counting sort also works for 3 values; say it, then write this if they want in-place one-pass.

What

One pass, O(1) extra. Invariant: zeros on the left, twos on the right, ones behind mid, unknown under the scan. Not a comparison sort. Counting is valid for a tiny alphabet — they often still want Dijkstra’s partition.

Why

LeetCode 75 Sort Colors. Interview tests in-place partition invariants: which pointer moves, and why mid sometimes stays. Same bones as quicksort’s pivot split.

Trap

mid++ after swapping a 2. Using a sort. Counting sort when they said “one pass, constant space” — counting is two passes (tally, then write). Say that, then write the three-pointer.
