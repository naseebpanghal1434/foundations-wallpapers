DSATwo-sum · index map

Need a pair? Store the complement.

A hash map is key → value in average O(1). The two-sum pattern: walking i, look up target − a[i]; if present you have the pair; else store a[i] → i. One pass. The map remembers what the left side already saw.

What

get/put/delete average O(1). Iterate items O(n). Keys need hash + equals. Value can be an index, a count, a list of positions.

Why

Two-sum, subarray sum equals k (prefix + map, plate 126), group anagrams, clone graph (old node → new). First tool when the naive pair loop is n².

Trap

Unsorted two-sum with two pointers (plate 54) — that needs sorted data and loses indices. Storing the current index before looking up — a number that is twice itself false-hits. Mutable keys.
