Gen AIsoftmax(z / T) · 0–2

Temperature is not creativity.

Temperature T ∈ [0, 2] on common APIs (OpenAI; default 1). Next-token: softmax(logits / T). T = 0 → argmax (greedy, near-repeatable). T = 1 → the model’s distribution. T = 2 → flatter tail. It is a sampling scale, not a creativity score.

greedy

T = 0

Always pick the top token. JSON, SQL, tools, classification, evals. Same prompt ≈ same answer.

native

T = 1

Sample p = softmax(z). API default. The distribution the model actually learned.

OpenAI max

T = 2

Flatter. Tail tokens get mass. More variety, more nonsense (plate 45). Not “more creative.”

formula

z / T

Divide logits by T, then softmax. T→0 sharpens. T→∞ → uniform. top_p / top_k are other filters.

What

Sampling, not intelligence. top_p (nucleus) keeps the smallest set whose mass ≥ p (often 0.9). Use T or top_p, not a stack of mystery sliders. Code/extract: T=0. Brainstorm: 0.7–1.0.

Why

Evals, extraction, and function calling want T=0 so the grade is about the prompt, not the dice. Interviews: explain sampling; do not say “higher = smarter.”

Trap

T=1.5 on a RAG answer about policy. T=0 and expecting variety. Stacking T=2 + top_p=0.1. Seed is not bit-identical across providers even at T=0.
