What

A uniqueness constraint is the lock. Same key + same body = replay; same key + different body = 409. Hash the body, not only the URL. Stripe’s pattern.

Why

Payments, jobs, webhooks (plate 82). You cannot have exactly-once delivery; you can have exactly-once effects.

Trap

Hashing only the URL, not the body. Keys without a unique index (TOCTOU). Reusing keys across users. No TTL so the table grows forever. Treating GET as if it needed a key.
