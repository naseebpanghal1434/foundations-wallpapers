DSALevenshtein

Insert, delete, replace. Min of three.

Edit distance: min inserts, deletes, replaces to turn s into t. dp[i][j] for prefixes. If last chars match, dp[i-1][j-1]. Else 1+min(replace, delete s, insert t). dp[0][j]=j (insert all), dp[i][0]=i (delete all). O(n·m). One row if only the number.

Match is free · else three

Levenshtein

if s[i-1]==t[j-1]: dp[i][j] = dp[i-1][j-1] else: dp[i][j] = 1 + min( dp[i-1][j-1], # replace dp[i-1][j], # delete s dp[i][j-1]) # insert t horse → rorse → rose → ros = 3 (h→r, drop r, drop e) Empty bases: dp[0][j]=j dp[i][0]=i

Spell-check, DNA. Weighted edits: put those weights in the +1. Length-only: roll one row.

vs

No replace · inserts + deletes

n+m − 2 LCS

horse, ros LCS = os (len 2) n+m−2·LCS = 5+3−4 = 4 replace is cheaper: one op, not delete+insert. That's why 3, not 4. same length, only replace: Hamming — count mismatches

Follow-up: only insert/delete (LCS), or only replace (Hamming, equal length). Don’t mix the formulas.

What

Three choices at a mismatch. Match is free — copy the diagonal. This is the full Levenshtein table. Prefixes are 1-based so the empty string occupies row 0 and column 0. Time O(n·m), space O(min(n,m)) for the count.

Why

LeetCode 72. Hard DP. Interviewers swap the allowed ops. Say the three transitions and the empty-prefix bases before you fill a cell.

Trap

Forgetting the empty-prefix base (first row/col). Using the LCS formula when replace is allowed — horse/ros is 3, not 4. Recursion without memo. Off-by-one letters (s[i] vs s[i-1]).
