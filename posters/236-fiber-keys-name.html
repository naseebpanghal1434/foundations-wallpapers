Fiber walks. Keys name the nodes.

Fiber is a linked tree of work units: on update it diffs type+key and reuses when they match (plate 26). The walk can pause (concurrent) — time-slicing, not a second thread.

What

Diff is type and key, not “deep equal the world.” Index keys are stable only for append-only static lists.

Why

The real reason keys exist. Remounting resets state and effects — sometimes you want that (key={id} on a form).

Trap

key={Math.random()} every render. key={index} on a sortable list. Putting the key on the inner <div> instead of the array element.
