DSAHistogram · sentinel 0

Bars wait for the first smaller.

Largest rectangle in a histogram: for each bar i, the max rectangle with height a[i] stretches until a smaller bar on the left and on the right. Those bounds are next-smaller (monotonic increasing stack). Area = a[i] * (right − left − 1). One pass with a sentinel 0 at the end pops everyone.

1

Next smaller, both sides[2,1,5,6,2,3]. Height 5 at i=2: left smaller i=1, right smaller i=4. Not next greater — a taller bar does not stop this rectangle.

bounds
2

Width = right − left − 14 − 1 − 1 = 2. Area 5 × 2 = 10 — the max. Width is how many bars, not the index gap. right − left without the −1 is the bug.

area
3

Increasing stack + sentinel 0When a[i] is smaller than the top, pop and compute: right bound = current i, left bound = new top (or −1). Append height 0 so the last bars pop. Max area 10.

O(n)

Largest rectangle in a binary matrix = this on consecutive 1-heights per row (LC 85).

What

O(n). Left/right smaller can be two arrays or one stack that computes area on pop. Each index push/pop once — same cost argument as next greater (plate 153), flipped to an increasing stack.

Why

LeetCode 84 / 85. Hard stack. If they say histogram, do not n² min-range over every pair of bars.

Trap

Width = right − left not right − left − 1. Forgetting the sentinel so the last bars never pop. Using next greater instead of next smaller. Off-by-one on the empty-stack left bound (−1, not 0).
