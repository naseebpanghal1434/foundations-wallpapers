What

Reachability from two sources. Intersection. Flow is reversed so you climb: a neighbor is allowed iff its height ≥ current. Each cell enters each ocean’s set at most once — O(n).

Why

LeetCode 417. Tests that you flip the search direction. Interviewers like “why from the ocean?” — because downhill from every cell redoes the same valleys.

Trap

Simulating downhill from every cell. Strict < instead of ≤ (equal height is a legal flow). Forgetting a border belongs to an ocean. Using union-find without a plan for height constraints.
