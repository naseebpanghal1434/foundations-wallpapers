this is the caller, unless you bind it.

In a function (not arrow), this is set by the call site: obj.fn() is obj, bare fn() is undefined in strict. Arrows close over this from the room they were born in (plate 23).

No own this. bind(this) returns a new function.

What

Call-site this vs lexical this. Losing this on extract is the bug. Function components don’t use this.

Why

Classic JS interview. Event listeners and map callbacks are where it falls off. Class methods needed bind or arrows.

Trap

Arrow on a prototype method you wanted overridable with its own this. Binding in render every time (new function, plate 237).
