OOP is four sentences.

Four mechanisms, not a style. Encapsulation restricts access to representation (private, JS #field). Abstraction is the published type (interface Payment { charge(order) }). Inheritance is subtype (class Dog extends Animal). Polymorphism is late binding: shape.area() hits Circle or Rect without a switch.

extends / [[Prototype]]. The subtype must stand in for the parent everywhere (plate 66).

Polymorph

Virtual / override / duck typing. One call, callee’s method. The call site does not branch on type.

What

Encapsulation is access control. Abstraction is the contract you show. Inheritance is the subtype relation. Polymorphism is dispatch. Getters are not “abstraction”; an interface is not “encapsulation.”

Why

SDE-1/2 filter: one sentence and one API per name, then when not to inherit (plate 66). Interfaces exist so polymorphism does not need a shared concrete parent.

Trap

class User extends Array or Stack extends List — reuse, not is-a. Reciting the four words without assigning a sentence to each.
