Don't deploy from a laptop.

CI runs on every pull request: lint, unit + integration (plate 89), build an immutable artifact tagged with the git SHA. CD deploys that digest — staging then prod, same bits. Config from env (plate 85), not a rebuild. Prod is not kubectl apply of files on a laptop. Rollback is the previous SHA.

1

PR + CIEvery push. Required check. Review is not the test suite. GitHub Actions / GitLab pipeline must go green.

2

ArtifactDocker image / jar tagged with the git SHA. Immutable. Build once. Do not compile again in prod.

digest
3

CD: stage → prodPromote the same digest. Delivery = button; deployment = auto. Rollback = previous SHA, not a hotfix on the box.

ship
What

CI = continuous integration on the PR. CD = continuous delivery (button) or deployment (auto) of the CI artifact. The image digest is the thing you ship.

Why

Reproducible: prod is the bits you tested. Audit: who shipped which SHA. Interviews: separate “prove it” (CI) from “ship it” (CD). The laptop is not an environment.

Trap

kubectl apply of local YAML, rsync with uncommitted files and a local .env. Building again in prod. CD without CI. Secrets printed in pipeline logs.
