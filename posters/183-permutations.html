DSAn! · used array

Swap i with each later j.

Permutations: n! orders. Two writes. (1) used[] boolean, loop all indices not used, append, recurse, pop. (2) in-place swap: for j in i..n-1 swap i,j, recurse i+1, swap back. Duplicates: sort, skip equal j at the same depth, or the swap version with a local set of values already placed at i.

What

O(n · n!) to write. Path length n is the leaf — record only there. Swap is the same tree without a used[]. Duplicates: sort and skip, or a set of values already tried at this i.

Why
