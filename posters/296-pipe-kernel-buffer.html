OSpipe(2) · 64 KiB

A pipe is a kernel ring buffer.

pipe() returns two fds: write end, read end. Bytes sit in a kernel buffer (Linux default 64 KiB, F_SETPIPE_SZ up to /proc/sys/fs/pipe-max-size). Full write blocks (or EAGAIN if O_NONBLOCK). Broken read end → write gets SIGPIPE/EPIPE.

Shell composition

a | b

pipe() → (w, r) a stdout = w b stdin = r unidirectional byte stream

Plate 5 is the product view; this is the syscall. splice/tee move pages without a user copy. SOCK_STREAM is a different buffer.

Default capacity

64 KiB

16 pages. F_SETPIPE_SZ to raise.

PIPE_BUF

4 KiB

Linux atomic write. POSIX ≥ 512 B.

No reader

EPIPE

Plus SIGPIPE unless ignored.

What

Unidirectional byte stream in-kernel. Atomic writes ≤ PIPE_BUF (4 KiB on Linux).

Why

Unix composition. Backpressure is blocking, not a polite API.

Trap

Ignoring SIGPIPE (process dies). Waiting for both ends in one thread (deadlock). Assuming pipe capacity is unlimited.
