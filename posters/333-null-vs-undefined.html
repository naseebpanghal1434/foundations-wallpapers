LangNULL · None · undefined

null is a pointer. undefined is a JS hole.

C NULL: pointer 0; dereference is UB (plate 327). Java/Go null/nil: typed nothing; method call is NPE/panic. JS: undefined = missing binding or property; null = intentional empty; == equal, === not (plate 67). Option/Maybe is a type that forces a check.

C · address 0

NULL

int *p = 0; *p; // UB if (!p) … // check

Not a guaranteed SIGSEGV. 0 as both integer zero and “missing” is a second bug.

A type for absence

Option

Optional.ofNullable Maybe T / T? Go: p == nil

The check is in the type (plate 328). SQL NULL is three-valued logic, not a pointer.

JS · two holes

undefined

x.y // TypeError if // x is undefined null == undefined // true null === undefined // false

typeof null === 'object'. JSON null vs omitted key are not the same API.

What

Absence encodings differ by language. Don’t mix them in APIs: JSON null vs omit, JS null vs undefined, C NULL vs 0-as-int.

Why

The billion-dollar mistake is preventable with types (plate 328) or an explicit check before the load.

Trap

typeof null === 'object' in JS. Using 0 as both integer zero and “missing” in C APIs. Treating SQL NULL as “pointer-like” in app code.
