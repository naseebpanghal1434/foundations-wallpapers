Two children. That's the tree.

A binary tree node is value, left, right. No other promise: it is not sorted (that’s a BST, plate 112), not complete (that’s a heap, plate 114). Height is longest root-to-leaf. n nodes: height from log n (balanced) to n (a stick).

Array form i → 2i+1, 2i+2 only if you store the holes. A sparse tree in an array skips them wrong.

What

Recursive structure. Size = 1+size(L)+size(R). Height = 1+max(hL,hR). Traversals on plate 57. Level order uses a queue (plate 107).

Why

Invert, diameter, path sum, LCA, serialize — all “recurse both kids, combine.” Draw one node and two boxes before you code.

Trap

Calling a random binary tree a BST. Using 2i+1 indexing on a sparse tree without placeholders — you skip holes wrong. Returning height 0 for a single node vs 1 — pick a definition and stick to it (empty = −1 or 0).
