DSAAlready sorted · one pass

Left of new. Overlap. Right of new.

Insert a new interval into a sorted, already-merged list. One pass, no full re-sort. Emit every interval that ends before new starts. Then merge all that overlap the new (expand new). Then emit the rest. O(n).

Strictly rightEmit [12,16]. If new sits in a hole with no overlap, it is just inserted in order — the middle loop never fires, and you still never re-sort.

right

Three regions. Sort-and-merge (plate 157) also works; this is the O(n) write they want when the list is already clean.

What

Three regions: strictly left, overlapping (fold into new), strictly right. You expand new in place as you eat overlaps, then append it once. Input stays sorted; output stays merged.

Why

LeetCode 57. Tests interval algebra without hiding behind sort-and-merge. The three-region scan is the point of the problem.

Trap

Sorting the whole list again as the only idea (correct, slower to the point). Off-by-one on touching. Mutating the input list while iterating. Forgetting to append new if it belongs at the very end.
