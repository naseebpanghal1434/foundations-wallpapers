DSASame end vs two ends

Stack is LIFO. Queue is FIFO.

Stack: last in, first out — push and pop the same end. Queue: first in, first out — enter the back, leave the front. Same linear structure. Opposite exit. Recursion is a stack (plate 56). BFS is a queue.

BFS. Level-order tree. Workers.
Need O(1) at both ends.
Deque, linked nodes, or a head index.
What

LIFO vs FIFO. Name the end you write and the end you read. A deque does both. Don’t implement BFS with a stack or DFS with a queue unless you mean it.

Why

Screens: valid parentheses, min-stack, binary-tree level order, “implement a queue with two stacks.” Say the word (LIFO/FIFO), then the ops, then O(1).

Trap

Array.shift() as a queue in JS. shift reindexes every remaining element — O(n) per dequeue — so “BFS” goes quadratic. Use a head pointer, a deque, or a linked list. push+pop is a stack, not a queue.
