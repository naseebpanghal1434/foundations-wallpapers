Backendpath traversal · realpath

../ is not a filename.

open(userPath) with userPath = ../../etc/passwd walks out of the uploads dir. Fix: resolve to canonical (realpath), then check prefix of the allowed root with a boundary (root + sep). Reject NUL bytes, backslashes on Windows, encoded %2e%2e.

The path segment is not a name. It is navigation. Same bug inside tar/zip extract.

canonicalize · then prefix

Rooted

c = realpath(root / user) ok = c == root or c.startswith(root + "/") root + sep, not startswith(root) decode before the check

/var/app/uploads vs /var/app/uploads_evil — trailing slash is the boundary.

What

Untrusted path segments vs a rooted tree. Canonicalize, then prefix-check with a separator boundary.

Why

File download/upload endpoints. Static file servers. Archive extract (zip slip).

Trap

startswith without the trailing slash. Decoding %2e%2e after the check. Allowing .. because “we strip it once.”
