DSADSU · components

Find the root. Merge the smaller.

Union-Find (Disjoint Set) tracks components. find(x) walks parent pointers to a root. union(a,b) hangs one root under the other. Path compression (point to root on the way up) plus union by rank/size makes almost O(1) per op — inverse Ackermann, in practice a tiny constant.

Kruskal

Path compression: on find, point every hop at the root. Union by rank: hang the smaller under the larger.

What

Dynamic connectivity. Kruskal MST. Accounts merge, number of provinces, graph valid tree. Arrays parent[n], rank[n]. Always find both roots, then hang one root under the other.

Why

When the graph is a stream of undirected edges and you only need “same component?” — don’t BFS every time. Offline queries too. Interview: say path compression + union by rank.

Trap

Union without find — hanging a node under a non-root. Forgetting path compression so a stick becomes O(n). 1-based vs 0-based nodes. Directed graphs: DSU is for undirected membership.
