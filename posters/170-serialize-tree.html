DSAEncode · decode

Preorder plus nulls. That's enough.

Serialize a binary tree to a string and back. Preorder with explicit nulls uniquely reconstructs: 1,2,#,#,3,4,#,#,5,#,#. Decode: consume tokens with an iterator; if null return; else new node, left=decode(), right=decode(). BFS with nulls also works (level order). A BST can omit nulls if you use bounds (or preorder + BST insert).

What

Null markers restore the shape. Preorder names roots in time, same as plate 172. The decoder is the recursive constructor driven by a stream, not by scanning.

Why

LeetCode 297 / 449. Design. Also: how you’d send a tree over the wire. They want a reversible codec, not a pretty print. Say “preorder with nulls” in the first sentence.

Trap

Inorder only. Forgetting nulls so 1-left-2 vs 1-right-2 collide. Recursing decode on a shared index without advancing. Using eval() on the string.
