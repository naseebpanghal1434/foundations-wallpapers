DSAWindow + last index

Grow until a repeat. Then shrink.

Longest substring without repeating characters: variable window (plate 55). Expand r. If s[r] is already in the window, advance l until it is not (jump using last-seen index). Track max length. O(n) with a map char → last index.

What

Need uniqueness in a contiguous slice → window + set or last-index map. Set version: while s[r] in set, remove s[l], l++. Last-index jumps in one assignment. Both amortized O(n).

Why

LeetCode 3. The canonical variable-window. Same bones as longest with at most k distinct, character replacement (plate 139). Interviews want the O(n) argument: l and r each move ≤ n times.

Trap

Restarting from r every time a duplicate appears — O(n²). Letting l move backward when last[c] is old (outside the window). Counting arrays vs characters (bytes vs Unicode).
