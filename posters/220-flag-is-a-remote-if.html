A flag is a remote if.

A feature flag is a boolean or percent you change without deploying. SDK reads a snapshot every 30 s (or push). Stable rollout: hash(userId+flag) % 100 < 10. Payments kill switch: fail-closed. New color: fail-open. Delete the flag after 100%.
