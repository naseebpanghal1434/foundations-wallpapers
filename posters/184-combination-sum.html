What

Unbounded: recurse same index. 0/1: next index. Start index enforces nondecreasing picks so a combo is written once. Prune remain<0; record at remain==0.

Why

LeetCode 39/40/216. The reuse-vs-once fork. Interview: they change that one constraint and watch whether you still loop from 0. Coin change that lists combinations, not counts.

Trap

Looping from 0 every time (permutations of the same combo). Using DP to list (memory-heavy). Not sorting for skip-dups. Forgetting to record when remain hits 0.
