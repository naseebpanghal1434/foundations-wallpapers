Toolswaitpid · 0–255

0 succeeded. Nonzero is the error code.

exit(n) is an 8-bit status: 0 means success for shells and Make. 1 generic fail, 2 misuse, 127 not found, 128+N killed by signal N (SIGKILL → 137). set -e aborts a shell on nonzero; CI is a chain of these integers.

ok

0

success. Make and shells continue.

fail

1

generic error. grep: no match.

PATH

127

command not found. 126 = not executable.

SIGINT

130

128+2. Ctrl-C. SIGTERM is 143.

SIGKILL

137

128+9. OOM killer. Cannot catch.

waitpid packs exit in bits 15–8; the shell maps signal N to 128+N. Python sys.exit. stdout may still have data.

What

The process’s summary integer, 0–255. Not a substitute for the streams (plate 368).

Why

Scripts, container restartPolicy, Make recipes. CI is literally these codes in a chain.

Trap

exit(256) becomes 0. Returning -1 from main → 255. grep no-match is 1 — “failure” under set -e pipelines.
