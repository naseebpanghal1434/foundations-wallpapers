DSAVisited map · DFS/BFS

Hash the old node to the new one.

Deep copy an undirected graph. A map old→new is both the visited set and the wiring table. DFS: if node already in map, return the clone; else create clone, store it, then append clone.neighbors = dfs(neigh) for each. BFS with a queue is the same map. Without the map you infinite-loop on cycles.

Copy list with random pointer (LC 138) is this map on a linked list — or the weave trick. BFS: create, map, enqueue; never enqueue a node you have not mapped.

What

O(V+E). The map is mandatory on cyclic graphs. Clone fields first, then neighbors — so a cycle sees a half-built node and stops. DFS or BFS is flavor; the map is the algorithm.

Why

LeetCode 133. Graph copy, random-pointer list. Interview: say the map before you pick a traversal. “Deep copy” without it is a stack overflow.

Trap

Creating a new clone every visit (no map). Copying the neighbor list by reference — both graphs share mutability. BFS enqueue without mapping first, so a node is queued twice.
