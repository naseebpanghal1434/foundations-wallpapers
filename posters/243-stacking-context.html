Frontendz-index · opacity · transform

A stacking context is a new z-world.

z-index only compares siblings inside the same stacking context. A child with z-index:9999 cannot paint above an uncle if its parent is a lower context.

Parent is a ceiling

Trapped

.wrap { opacity: 0.99 } .child { z-index: 9999 } .uncle { z-index: 1 } /* uncle can cover child */

opacity < 1, transform, filter, position+z-index, isolation each open a context.

trap

z on the overlay root

Isolate

.modal { position: fixed; z-index: 10; isolation: isolate; }

Raise the context, not a nested number. translateZ(0) for “GPU” also creates one.

What

z-index is local. The parent’s context is a ceiling. Fixed/sticky also interact with contexts.

Why

Dropdowns under a header, modals under a toast. Draw the contexts, not the numbers.

Trap

z-index:99999 on a nested node. opacity on a wrapper “for a fade” trapping the menu. Mixing stacking with overflow:hidden clipping.
