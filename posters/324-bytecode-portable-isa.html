LangJVM · CPython · WASM

Bytecode is a portable ISA.

Bytecode is instructions for a virtual machine, not for your CPU. javac → .class (stack machine). CPython → .pyc. WASM → a linear-memory ISA in the browser and at the edge. The VM maps those ops to native — interpret or JIT. One artifact, many CPUs.

VM ISA · one artifact

.class / wasm

JVM iadd CPython LOAD_FAST WASM i32.add VM on each CPU verify, then interpret / JIT

.pyc is version-locked to that CPython. JVM and WASM can reject illegal programs before run.

What

A stable, simpler ISA plus a runtime. Verification (JVM, WASM) is a gate. The CPU never sees iadd until the VM translates it.

Why

Portability and sandboxing: Android ART, Spark executors, the browser. Ship bytecode, not a fat ELF per arch.

Trap

Shipping .pyc across Python minor versions (magic number mismatch). Treating WASM as “C speed” without bounds checks and the JS glue.
