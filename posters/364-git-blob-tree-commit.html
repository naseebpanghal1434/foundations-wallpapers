Toolssha1 · objects

Git stores blobs, trees, commits. Not diffs.

A blob is file bytes, a tree is a directory of name→hash, a commit is parent + tree + author + message — the object id is SHA-1 of that payload (SHA-256 repos exist). A “diff” is computed at show time from two trees; packfiles only delta-compress later for disk.

commit 9c3e0… nodeparent 1b4a… + tree 3a52c1… + author + message. git cat-file -p prints it.

dag

Content-addressed DAG. Change one byte → new blob, new tree, new commit hash. Branches are names for commits (plate 367).

What

Immutable objects addressed by hash. History is a DAG of commits, each pointing at a full tree — not a stack of patch files.

Why

Rewriting history changes hashes (plate 366). An empty commit still has an id: the message and parent are content.

Trap

Thinking git stores diffs as the source of truth. Mutating a commit object and expecting the hash to stay.
