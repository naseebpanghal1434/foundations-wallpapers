Capabilities split root into bits.

euid 0 used to mean every privilege. Linux capabilities split that: CAP_NET_BIND_SERVICE (bind <1024), CAP_SYS_PTRACE, CAP_NET_ADMIN, … — file caps (setcap) and ambient caps in containers. Drop what you do not need; root in a user namespace is not host root.
