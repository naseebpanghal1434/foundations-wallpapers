DSA4-dir · islands

A grid is a graph of cells.

A 2D grid is a graph you do not store. Each cell (r,c) has up to four neighbors. BFS/DFS with a visited matrix (or mutating the cell) is the whole algorithm for islands, flood fill, shortest path in a maze. Flatten index i = r*cols+c when you need a 1D visited set.

8-dir is the same plus diagonals — only if the problem says so. Flatten: i = r*cols+c.

What

n = rows×cols nodes, m ≤ 4n edges. Time O(n). Space O(n) visited / queue. The graph is implicit: the cell is the node, the four deltas are the edges. Don’t allocate an adj list.

Why

Number of islands, rotting oranges (multi-source BFS), surrounded regions, unique paths with obstacles, word search. If it is a matrix of cells, think grid-graph before “2D DP.”

Trap

Recursing DFS on a 1000×1000 grid — stack overflow; iterate or BFS. Forgetting bounds. Using 8-dir when the spec is 4. Mutating the input to mark visited without saying you will.
