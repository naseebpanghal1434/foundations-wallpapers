OSCoW · PTE write-protect

fork copies the map. Writes copy the page.

fork duplicates mm: the child’s PTEs point at the same physical pages, marked read-only. First write in either process → fault → copy the page → mark both writable. execve after fork drops the parent’s pages. That is why fork+exec is cheap compared to copying 100 MiB.

What

CoW is per page. Shared file mappings (MAP_SHARED) write through, not CoW.

Why

Prefork servers (Apache, Redis on Linux). A huge parent with dirty heaps still pays page-table copy + later CoW.

Trap

fork in a multithreaded process (POSIX: undefined for other threads). Relying on vfork. Measuring “fork is instant” on a 32 GiB RSS JVM.
