From left, or from above.

Unique paths in a grid, only right and down: dp[r][c] = dp[r-1][c] + dp[r][c-1], first row/col = 1. That’s C(m+n−2, m−1). Obstacles: those cells stay 0, skip them in the recurrence. Min path sum: same DAG, min instead of +. Space: one row.

What

DAG DP on a grid. Only right and down, so acyclic, so a table works. Combinatorics when empty. Obstacles punch holes in Pascal. Unique paths III is Hamiltonian backtrack (visit every empty cell), not this recurrence.

Why

LeetCode 62 / 63 / 64. The grid DP starter. Interview: they add a stone, then they ask min sum. If they want the count modulo 10⁹+7, they will say so — overflow is a real fail.

Trap

Four directions (this DP assumes a DAG; 4-dir has cycles). Combinatorics with obstacles (no closed form). Off-by-one on 1-index vs 0-index rows. First row after an obstacle is 0 for the rest of that row, not 1.
