DSAnext only · reverse

A dummy node saves the empty case.

Each node holds a value and next. You do not have index i. You have a pointer. Reverse, merge, unlink: three pointers and a dummy head so you never special-case “the list was empty” or “we replaced head.”

Sentinel before head

Dummy

dummy → 1 → 2 → 3 insert 0 after dummy: dummy → 0 → 1 → 2 → 3 delete after p: p.next = p.next.next return dummy.next

One code path if the list was empty. dummy.next is the real head — never return dummy.

then

Three pointers

Reverse

prev, cur = null, head while cur: nxt = cur.next cur.next = prev prev = cur cur = nxt # prev is the new head 1→2→3 becomes 3→2→1

Save nxt first. O(n) time, O(1) space. Iterate — do not recurse n=10⁵.

What

Singly: one pointer forward. Head is the only entry. Tail append is O(n) unless you store tail. Dummy (sentinel) is a fake node before head — insert and delete use the same lines for empty, one-node, and many-node lists.

Why

SDE-1: reverse list, merge two sorted, remove nth from end (two pointers + dummy), palindrome list. Draw the boxes. Then write the three lines.

Trap

cur = cur.next after you already set cur.next = prev — you lost the rest. Save nxt first. Also: dummy.next is the real head; returning dummy is a bug. Recursing n=10⁵ blows the stack — iterate.
