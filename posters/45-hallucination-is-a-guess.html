Gen AIP(token | context) · no verifier

Hallucination is a confident guess.

The model samples from P(token | previous tokens). There is no verifier and no loss term for “true.” If the answer is not in the prompt or the weights, it still emits a fluent sentence. Fluency is not a fact check. Lower T (plate 44) reduces variety, not falsehood.

Closed-book · paper that does not exist

Still answers

Q: DOI for Smith 2019 “Queues considered harmful” A: 10.1145/3322425.3322450 formatted, fluent, wrong P(next) completed the genre “academic citation”

Invented APIs, legal cites, stack traces: same bug. Confidence in the prose is uncalibrated.

fix

Ground, then generate

Verifier outside

1. retrieve top-k (plate 12) 2. quote spans + chunk ids 3. if not in docs: refuse 4. tool: GET /papers?q= 5. check id ∈ retrieved cite or it didn’t (plate 270)

RAG + refuse-if-missing + tools. The model can still ignore the docs — so verify membership, don’t trust the footnote.

What

Ungrounded generation: a completion not entailed by provided or real facts. Default behavior of a next-token model, not a rare bug. “I’m 90% sure” is another sample, not a calibrated probability.

Why

Gen-AI interviews always ask this. The answer is architectural (no truth loss), then product (retrieve, cite, tool, eval) — not “we’ll prompt it to be honest.”

Trap

Treating T=0 as ground truth. Stuffing 80 pages and assuming it cannot invent in the gaps. Trusting invented DOIs, package names, or “according to policy…” with no chunk id.
