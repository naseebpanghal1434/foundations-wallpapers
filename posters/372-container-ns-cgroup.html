Toolsclone · overlay

A container is namespaces plus cgroups, not a VM.

A Linux container is PID/mount/net/uts/ipc/user namespaces (clone flags) plus cgroups (plate 306) plus a rootfs (often overlayfs) — same kernel as the host. A VM has its own kernel and hardware model; isolation here is only as good as the kernel + seccomp + dropped caps (plate 304).

overlay: lower + upperImage layers are lowerdir (read). Writes go to upperdir. Docker is UX on runc/containerd.

rootfs

K8s is orchestration. A kernel CVE is a container CVE. Bind mounts and /proc still show host reality you mapped in.

What

Kernel features composed. Not a hypervisor. Isolation is names + quotas + a root, on the host kernel.

Why

Density vs isolation. Pack many apps per kernel. A VM would duplicate a kernel and a hardware model.

Trap

--privileged. Mounting docker.sock (the container is now the host’s docker client). Assuming host files are invisible.
