DSAMembership · first dup

Have I seen this?

A hash set is a map with no values — only membership. Add, remove, contains: average O(1). The interview line is “seen.” First duplicate, longest consecutive sequence (start a run only if n-1 is missing), a sliding window of unique chars.

1

First duplicateWalk [3,1,4,1]. seen {3}, {3,1}, {3,1,4}, then 1 already in → first dup. Membership, not a scan of the prefix.

dup
2

Longest consecutive[100,4,200,1,3,2] → set. For x, if x-1 not in set, count x, x+1, …. Only 1 starts the run 1–4. Each number is a start at most once → O(n).

run
3

Window of unique charsSet of chars in [l,r]. Repeat at r → shrink l until it leaves. Longest substring without a repeat (plate 55) is this set plus two pointers.

window
What

Membership. No order (HashSet). Need order? TreeSet / ordered set (plate 125) is log n. Python set, JS Set, Java HashSet.

Why

Dedup, “exists,” graph visited, union of two arrays. Consecutive sequence is the trick that looks sort-O(n log n) and is O(n) with a set.

Trap

Checking x-1 in set inside the count loop without the start-of-run test — becomes O(n²). Using a list as “seen” — contains is O(n). Floating keys and NaN. Assuming iteration order.
