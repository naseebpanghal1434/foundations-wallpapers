DSAMirror

Swap left and right. Recurse.

Invert a binary tree: swap the left and right child pointers on every node. Recurse both children — swap first is the usual picture; recurse-then-swap is the same mirror. Iterative: a queue or stack of nodes, swap as you go. Time O(n), space O(h).

Before

Original

4 / \ 2 7 / \ / \ 1 3 6 9 swap pointers not values

A single swap at the root leaves 1,3,6,9 in place. That is not invert.

vs

Every node mirrored

Invert

4 / \ 7 2 / \ / \ 9 6 3 1 null → null return the root

Pre-order or post-order, as long as you visit every node. BFS swap is fine.

What

node.left, node.right = node.right, node.left, then both kids. Base: null returns null. You are rewriting edges, not shuffling stored values. Same tree object, mirrored shape.

Why

LeetCode 226. Warm-up tree recursion. Interviewers use it to see if you draw the tree. Symmetric tree (LC 101) is the cousin: “is this already a mirror?” — two pointers, not a mutate.

Trap

Swapping values instead of child pointers. Recursing only one side. Returning the left child, not the root. A deep stick and recursion limits — iterate with a queue (plate 56).
