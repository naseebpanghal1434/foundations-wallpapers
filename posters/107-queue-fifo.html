DSABFS · level order

The first in is the first out.

A queue is FIFO: enqueue at the back, dequeue at the front. BFS is “the people who arrived first get processed first” — that is why a queue gives unweighted shortest path and tree level order. A list pop(0) is O(n); use a deque.

Seed the queueTree 1 / \ 2 3, 2 has child 4. Queue [1]. Enqueue back, dequeue front. First in is the root.

Pop, push kids[1] → pop 1, push 2,3 → [2,3] → pop 2, push 4 → [3,4] → pop 3 → [4] → pop 4. Closer nodes leave first.

3

Record level sizeAt the start of a level, len(q) is how many to pop before the next level. Levels: [1] | [2,3] | [4]. Need zigzag? You needed this number.

levels
What

Enqueue O(1), dequeue O(1) with a ring or deque. Peek front. BFS visits closer nodes first. Tree level order is BFS on a tree. Python: collections.deque and popleft.

Why

Islands, word ladder, course-schedule Kahn, binary-tree level order. If the interviewer says “shortest in an unweighted graph,” you said queue before you said code.

Trap

Using a Python list with pop(0) — O(n) per pop, O(n²) BFS. Recursing “BFS” — that’s DFS. Not capturing level size so a zigzag/level problem becomes a flat visit.
