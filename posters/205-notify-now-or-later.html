SystemPush · email · digest

Notify now, or notify later.

A notification is an event the request must not deliver. Write the row, enqueue. Worker picks APNs/FCM, email, SMS, or in-app. Online + high priority = now; else a digest. Collapse 200 likes → 1 push. Dead token → 410 Gone.

Inbox is a log like chat (plate 202). APNs 200 ≠ seen. Idempotent send (plate 225).

What

Producer writes an event. Preferences live next to the user. Idempotent send so retries do not double-text. In-app inbox is a log, not the push receipt.

Why

Notification system design: async, fan-out, collapse, channels, and “the producer is not the pusher.”

Trap

SMTP from the API box. One push per like. No quiet hours. Storing only the push (no in-app history). Treating APNs success as “the user saw it.”
