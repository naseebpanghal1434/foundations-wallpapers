OS8 MiB · 16 KiB

Each thread has a user stack and a kernel stack.

User stack: argv, frames, C alloca, default 8 MiB virtual (ulimit -s). Kernel stack: per-thread, 8–16 KiB on Linux, used during syscalls/IRQs — no deep recursion, no large local arrays in kernel. Overflow of user stack → SIGSEGV (guard page).

What

Two stacks, two overflow stories. Kernel stack exhaustion is a panic, not a catchable error.

Why

Why 100k threads is a virtual-memory problem even if rss is small. Why kernel coding forbids VLAs.

Trap

Recursion of depth 1e6 in user code. Creating 1e5 pthreads at 8 MiB each = 800 GiB VA. Putting a 64 KiB buffer on the kernel stack in a module.
