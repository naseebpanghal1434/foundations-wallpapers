DSAUnbounded · dp[x] min coins

Coins may repeat. Walk amounts up.

Coin change: fewest coins to make amount, coins reusable. dp[x] = min over coins c of dp[x-c]+1, dp[0]=0, rest ∞. Fill 1..amount. O(amount · n). Combination count (LC 518): dp[x]+=dp[x-c], iterate coins outer so order doesn’t count as extra. Greedy (biggest first) is wrong for arbitrary coin systems.

518: coins outerCount combinations, not permutations. Coins outer, amounts up: [1,2] amount 3 → 2 ways (1+1+1, 1+2). Amounts outer counts 2+1 as a third.

combinations
What

Unbounded knapsack. State is remaining amount. Each coin may be used again, so the 1D loop walks up. 0/1 (each coin once) is the backward knapsack loop from plate 187. Impossible → −1, not ∞.

Why

LeetCode 322 / 518. The “greedy fails” example. Interview: US coins greedy works; they will pick [1,3,4]. Amount 0 is 0 coins, not −1.

Trap

Greedy. Coins inner vs outer for counting (permutations vs combinations). dp[0]=∞. Amount=0 → 0, not −1. Negative coins. Mixing the 0/1 backward walk with this one.
