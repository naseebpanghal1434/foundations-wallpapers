Langcode unit · code point

JS length is UTF-16 code units.

JavaScript strings are UTF-16. 'é'.length is 1. Many emoji are two units (a surrogate pair): '🙂'.length === 2. str[i] is a code unit, not a grapheme. [...str] or for (const c of str) iterates code points. Bytes on the wire are UTF-8 (plate 322).

Code points

A family emoji is several code points and one grapheme. Files and HTTP bodies are almost always UTF-8.

What

Indexing and .length are in 16-bit units. Network and files are usually UTF-8. A code point is U+…. A grapheme is what the user sees.

Why

Tweet-sized limits, substr bugs, slicing mid-surrogate producing unpaired values that later explode a UTF-8 encoder.

Trap

s.substring(0, 1) on a leading surrogate. Buffer.byteLength(s) vs s.length in Node — bytes ≠ units. Truncating a UTF-8 buffer mid-sequence (plate 322).
