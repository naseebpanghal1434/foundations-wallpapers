Specificity is a score.

When two rules match, CSS picks the higher specificity, then source order. The score is a four-tuple: (inline, IDs, classes/attrs/pseudos, types).

1

Score the selectors#nav a → 0,1,0,1. .nav .link → 0,0,2,0. :not() adds nothing; its argument does.

tuple
2

ID beats ten classes0,1,0,0 beats 0,0,10,0. Not “longer selector.” style="" is 1,0,0,0.

ID
3

Tie → later ruleEqual spec: source order. !important is a separate layer above — a surrender, not a strategy. Unlayered beats @layer.

order
What

A four-tuple, not “more classes always win.” Inheritance is not specificity — it loses to a direct match of 0,0,0,0.

Why

“Why won’t it change color?” Usually an ID or inline somewhere. Compare the tuples, then the file order.

Trap

Fighting with !important. Counting selectors by length. Thinking a later stylesheet always wins across IDs.
