Archprefetch · working set

Spatial is the next line. Temporal is reuse.

Spatial locality: addresses near this one — arrays, sequential scan. Hardware prefetchers detect strides and pull the next 64 B line. Temporal: you will touch this line again soon (loops, stacks). Working set ≤ cache ⇒ hits. Random 10 GiB scan ⇒ DRAM ~100 ns or worse.

What

Layout and access order vs cache size. Prefetch helps spatial, not pointer chasing.

Why

Sorting a huge array then scanning beats a hash if you only stream once — and hash wins for point lookups that stay in cache.

Trap
