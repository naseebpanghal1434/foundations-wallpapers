DSA2^n · start index

For each item: in, or out.

Subsets (power set): each element is in or out → 2n subsets. Backtrack with a start index: for j in start..n-1, take nums[j], recurse j+1, pop. Include the path at every node (not only leaves). Bit mask 0..(1<<n)-1 is the other write. Duplicates in input: sort, skip j if nums[j]==nums[j-1] and j>start.

Only recording at length n misses the proper subsets.
What

O(n 2n) to write them all. Loop from start, not 0 (that’s permutations). Record at every call, including []. Include/exclude recursion is the same tree: take nums[i] or skip it, then i+1.

Why

LeetCode 78/90. The simplest backtrack (plate 181). Interview: “include/exclude” or start-index — either sentence, then copy the path.

Trap

Looping from 0 and using used[] (you generate permutations of each subset). Only recording at leaves of length n. Not copying. Handling dups with a set of tuples instead of skip — works, slower to talk through.
