DSAAmortized O(1) push

Capacity doubles. Append is cheap.

A vector is an array plus a length and a capacity. Push into a spare slot writes one cell. When it is full, allocate 2×, copy, then write. One push is O(n) on resize; n pushes are still O(n) total — amortized O(1) each. pop from the end is O(1) and usually does not shrink.

amortize
What

length = live items. capacity = allocated slots. Geometric growth (×2 or ×1.5) is the trick that makes append amortized O(1). Insert at i still O(n) — you shift, even with spare cap.

Why

Language “arrays” (Java ArrayList, Python list, C++ vector, JS Array) are this. Interviews: “why not grow by +1?” Because n resizes of size 1, 2, 3, … cost O(n²).

Trap

Amortized is not worst-case: a single push can stall on a copy of n. Real-time code uses a ring (plate 105) or a pre-sized array. Also: mid-insert is still O(n) after a resize.
