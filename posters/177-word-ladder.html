DSAImplicit graph · shortest

BFS words one letter apart.

Word ladder: shortest transformation begin→end, changing one letter, each intermediate in the word list. That’s unweighted shortest path — BFS. Nodes are words. Neighbors: all one-letter mutations in the dictionary. Trick: bucket by wildcard pattern h*t, *ot, ho* so you don’t scan the whole list per word. Bidirectional BFS from both ends on large lists.

Pattern buckets, not n² scans*ot: hot, dot, lot. Mutate L letters × 26, or group by wildcards once. Don’t DFS — you want shortest, not any path.

implicit graph

126 asks all shortest paths: BFS + parent lists, then DFS reconstruct. Bidirectional BFS when the list is huge. Same BFS as plate 59, nodes you never stored.

What

O(n · L · 26) with mutation, or O(n L) with patterns. Visited must be marked when enqueueing or the queue explodes. The graph is implicit: one letter apart, dictionary membership is the edge test.

Why

LeetCode 127/126. BFS on an implicit graph. The follow-up (all ladders) is still BFS first — DFS only to emit the parent DAG of shortest paths.

Trap

DFS/backtracking as the main search (exponential, not shortest). Generating neighbors by scanning every word every time without a plan. Marking visited late. Assuming case doesn’t matter.
