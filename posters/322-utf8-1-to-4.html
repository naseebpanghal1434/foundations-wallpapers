UTF-8 is 1–4 bytes. ASCII is unchanged.

A Unicode code point is U+0000..U+10FFFF. UTF-8: 0xxxxxxx for ASCII (1 byte), then 2–4 byte sequences with 10xxxxxx tails. “é” is 2 bytes, “€” 3, many emoji 4. You cannot index the nth character in O(1) without scanning or a side table. C strlen is bytes, not characters.
