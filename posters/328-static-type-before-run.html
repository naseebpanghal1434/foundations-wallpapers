LangHaskell · Rust · Java · Go

A static type is checked before run.

Static: the compiler (or typechecker) proves well-typedness using annotations or inference. Illegal programs do not build. Dynamic (Python, JS, Ruby): tags exist at run; errors are exceptions (plate 329). Gradual (TypeScript): erase to JS — the runtime does not enforce TS types.

javac · rustc · go · ghc

Before run

String s = 3; // error at javac fn f(x: i32) Go: s := 3 // int, not string does not emit the bad program

Java generics are mostly erased: the VM may not know T at run. The check still happened at javac.

vs

Python · JS · TS erase

At run

s = 3 s.upper() # AttributeError TS: let s: string = 3 // tsc may fail // emit still JS runtime still 3

TS green, runtime still a number. any everywhere is no check at either time.

What

When the check happens. Erasure (Java generics, TS) means the VM may not reify T. A tag at run is a different plate (329).

Why

API contracts, refactoring, a class of bugs that never starts. Cost: expressiveness and compile time.

Trap

Trusting TypeScript as a runtime check. any everywhere. Thinking Java generics reify T (they don’t, mostly — new T() is illegal).
