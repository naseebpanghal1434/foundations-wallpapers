DSASparse graph · default

Name the neighbors.

An adjacency list stores, for each node, the edges out of it. Sparse graph: n nodes, m edges, memory Θ(n+m). Walk neighbors of u in degree(u) time. This is the default. A matrix (plate 117) wins only when the graph is dense or you need O(1) “is uv an edge?”

Undirected · both ways

Adj list

edges 0-1, 0-2, 1-3, 2-3, 3-4 0: [1, 2] 1: [0, 3] 2: [0, 3] 3: [1, 2, 4] 4: [3] space Θ(n + m)

BFS/DFS/Dijkstra iterate g[u]. Weighted: store (v, w) pairs.

Directed · one way

Arrows

0 → 1 → 2 0 → 2 0: [1, 2] 1: [2] 2: [] 2 still has a slot so n is known

Isolated nodes need an empty list. Undirected: add both directions or you never come back.

What

Undirected: add both ways. Directed: one way. Weights on the pair. Isolated nodes still get an empty list so n is known. Neighbor walk is O(degree), not O(n).

Why

Course schedule, islands-as-graph, clone graph, word ladder (implicit list: the other words). Interview: build the list first, then BFS. That is the whole opening.

Trap

Forgetting the reverse edge on undirected. A matrix on n=10⁵, m=10⁵ — memory dies (plate 117). Iterating all n to find neighbors of u when you already have g[u].
