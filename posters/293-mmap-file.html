OSMAP_SHARED · MAP_PRIVATE

mmap maps a file into the address space.

mmap(addr, len, PROT_READ|WRITE, flags, fd, off) installs PTEs backed by the file’s page cache. Load is a page fault (plate 291), not a read() copy. MAP_SHARED: writes are the file. MAP_PRIVATE: CoW. MAP_ANONYMOUS: no file, zeros.
