GenAIJSON schema · constrained

Structured output is a schema, not a plea.

“Reply in JSON” is a hope; constrained decoding makes illegal tokens unrepresentable. Validate with a real schema after — retry on fail; don’t regex a maybe.

A prompt

Plea

return JSON {"ok": true Sure — here you go

Trailing prose. The prompt is not a contract.

vs

A grammar + a check

Schema

json_schema / tools parse; invalid → repair once

Enums in the schema beat “one of red, green” in English.

What

Grammar on the tokens, validator on the value (JSON Schema or Zod). Tools (plate 47) are schemas with side effects.

Why

Anything you will pipe to a DB or a function. The prompt is not the contract.

Trap

eval() on model JSON. No schema, then split on the first {. Asking for JSON and markdown in the same breath.
