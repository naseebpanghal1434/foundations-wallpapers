What

Backtracking with O(1) attack tests via sets: col, r-c, r+c. One queen per row so you never need a row set. Insert, recurse, undo — plate 181 with geometry.

Why

LeetCode 51/52. The showcase backtrack. Sudoku solver is the same: choose a cell, try digits, undo, with row/col/box sets. n=8 → 92 is trivia; the sets are the point.

Trap

Checking the whole board each time instead of sets. Forgetting one diagonal family. Placing two in a row. Returning the first solution when they asked all.
