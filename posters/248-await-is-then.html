FrontendPromise · async

await is then, with a stack.

async always returns a Promise. await p pauses that function, schedules a microtask (plate 227) with the result, and throws on reject — try/catch works.

Serial

ta + tb

await a() // ta await b() // tb // total ta+tb

Independent I/O, sequential awaits. Not a thread — a nicer .then.

vs

Overlap

Promise.all

const [x, y] = await Promise.all([ a(), b() ]) // max(ta, tb)

forEach(async x => await f(x)) does not wait — map + all does.

What

Syntax on Promises. Errors become rejections. The function after await is a new turn of the loop — a microtask, not the next line.

Why

The “it returned before the fetch finished” confusion. Also: accidental serial waterfalls.

Trap

await in a loop for independent I/O. async forEach. Catching nothing so a 500 becomes Unhandled Promise Rejection.
