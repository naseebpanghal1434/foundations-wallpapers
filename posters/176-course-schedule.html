DSATopo · Kahn or DFS color

Edges are prereqs. A cycle is a no.

Course schedule: can you finish all courses given prereqs? That’s a directed graph, edge b→a if a requires b. Possible iff DAG. Kahn: queue of indegree-0, peel, if you peel n you win (and you have an order). DFS: coloring white/gray/black — gray edge is a cycle. Order is the reverse of finish times.

Stuck

[0,1] and [1,0] 0→1, 1→0 indeg both 1 q empty, count=0 ≠ n → false visited-only DFS: back-edge vs cross-edge look the same
Alien dictionary (plate 199) is topo on letters.
Heap the queue if they want lex-smallest.
What

Build adj + indegree. O(V+E). Multiple valid orders: any peel order is fine unless they ask lexicographically smallest (then a heap). Directed: undirected union-find cannot see this cycle.

Why

LeetCode 207/210. The DAG question. If they say “ordering with dependencies,” you said topological sort — then you pick Kahn or 3-color DFS.

Trap

Undirected union-find (wrong for directed cycles). DFS without colors — a visited bit cannot tell a back-edge from a cross-edge. Building the edge the wrong way so “prereq” means the opposite of take-first.
