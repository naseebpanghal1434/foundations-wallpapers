Dijkstra: shortest path on a weighted graph with non-negative edges. dist[src]=0, others ∞. Min-heap of (dist, node). Pop the smallest; if it’s stale (a worse copy), skip. For each neighbor, if dist[u]+w < dist[v], update and push. Never decrease-key — push duplicates. O((n+m) log n).

Network delay time (LC 743). Cheapest flights with k stops: hop limit is a different state — dist[node][k] or BF-like, not plain Dijkstra.

What

Greedy closest unsettled node. Non-negative is required for the greedy proof — a later cheaper path cannot exist if all leftover edges are ≥ 0. Heap is plate 63; the skip-stale line is the whole implementation trick.

Why

LeetCode 743/787/1631. If they say weighted shortest and weights ≥ 0, you said Dijkstra, not BFS. BFS is the unweighted (or all-weights-1) special case (plate 59).

Trap

BFS on weighted graphs. Using Dijkstra with negatives. Updating dist after pop instead of on relax. Fibonacci-heap speech in a screen — binary heap is the write.
