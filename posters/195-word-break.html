A word ends here. Then start again.

Word break: can s be segmented into dictionary words? dp[i] = true if s[:i] can. For each i, try word endings: if dp[j] and s[j:i] in the dict, dp[i]=true. dp[0]=true. O(n²) with a set, better with a trie. Word break II lists the sentences — backtrack with memo on the suffix, not a boolean table alone.

What

Prefix DP + dictionary lookup. dp[i] means the prefix of length i is breakable; then you start again. Unbounded reuse of words. Empty string true. Listing paths is a different problem — memoize the list, don’t only keep a boolean.

Why

LeetCode 139 / 140. String DP. Follow-up lists sentences: backtrack from each true split, memo on the suffix so shared tails aren’t rebuilt. Say “prefix breakable” in the first sentence.

Trap

Greedy taking the longest word (fails on some dicts). Recursion without memo. Checking only whether s[i:] is in the dict as a whole. Word break II exponential output — memo still required, and you must copy sentences.
