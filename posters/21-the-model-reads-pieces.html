Gen AITokens are the unit

The model reads pieces, not pages.

A token is a chunk of text — roughly a short word, or part of a long one. The context window is a token budget for this call. You pay for tokens in and tokens out. Pages are not a unit the model knows.

You think in pages

“80-page PDF”

80 pages × ~500 words ≈ 40,000 words ≈ 50–60k tokens

A 128k window might fit it. An 8k window cannot. “I uploaded it” ≠ “it all fit.”

vs

The model thinks in tokens

A budget

"hamburger" → ham | bur | ger "JSON" → JSON system + docs + question + answer must all fit

Input tokens + output tokens = the bill and the limit. Overflow = silent drop.

What

Tokenizers split text into IDs. English is often ~0.75 words/token. Code and other languages can be much worse. The window includes system prompt, retrieved chunks, chat history, and the reply.

Why

Cost, latency, and “it ignored chapter 4” are token problems. RAG exists because most real corpora do not fit. You retrieve the pieces that might matter.

Trap

Counting pages or characters. Or stuffing the whole corpus into the prompt and assuming the model “read it.” The middle of a long prompt is where models go blind first.

The window is a budget. If it didn’t fit, it wasn’t read.
