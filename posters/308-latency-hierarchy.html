Archns · µs · ms

L1 is ~1 ns. Disk is ~10 ms.

Same-core 2020s x86, grown-up numbers: L1 ~1 ns (~4 cycles), L2 ~4 ns, L3 ~20 ns, RAM ~100 ns, NVMe ~100 µs, HDD seek ~10 ms, US/EU RTT 80–150 ms. 1 ms = 1e6 ns ≈ 3e6 cycles at 3 GHz. A disk seek is millions of instructions.

~100 µs

NVMe 50–150 µs. HDD seek ~10 ms.

Page is 4 KiB (plate 290); cache line is 64 B (plate 309). Your chips will differ; the decades between levels will not.

What

A hierarchy of capacity vs latency. Miss a level, pay the next. Sequential RAM is faster than random (prefetch).

Why

Every performance discussion. Big O ignores the 100× between L1 (~1 ns) and RAM (~100 ns).

Trap

Optimizing code before measuring cache misses. Treating SSD like RAM. Putting network RTT in the same sentence as L1 without a 1e8 gap.
