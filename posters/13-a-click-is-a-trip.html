Networkgetaddrinfo · 502 · 500

A click is a trip.

fetch('/api/me') is DNS + TCP + TLS + HTTP + app + DB. Metro RTT ~10–40 ms; US/EU ~80–150 ms. A miss at any hop fails the click. Map the symptom to the hop; don’t restart the app for NXDOMAIN.

1

DNS

getaddrinfo A/AAAA. NXDOMAIN, SERVFAIL, 150 ms. TTL (plates 77, 278).

2

TCP

connect() SYN. ECONNREFUSED, ETIMEDOUT. 1 RTT.

3

TLS

+1 RTT (1.3). certificate_expired. SNI (plates 78, 279).

4

HTTP

GET /api/me → 200 / 401 / 404 / 429 / 500.

5

LB

502 bad upstream. 504 gateway timeout. 503 no healthy host.

6

DB

Slow 200 = SELECT. Seq Scan vs Index (plates 02, 98).

What

Browser → DNS → TCP/TLS → HTTP → LB → process → DB. DevTools “failed” is one hop, not all of them.

Why

Same user report, five jobs: resolver, cert, proxy, handler, query. Interviews: name the status and the syscall.

Trap

Restarting the app for NXDOMAIN or an expired cert. Blaming the spinner — it is waiting on this RTT budget. A 500 is your process; a 502 is usually not.
