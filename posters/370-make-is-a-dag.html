Toolstarget · mtime

Make is a DAG of files and commands.

A rule is target: deps then a recipe. Make compares mtimes: if a dep is newer than the target, it runs the recipe. Cycles are errors; -j is safe iff the DAG is the real deps; phony targets (clean) are names, not files.

ninja/bazel are the same idea with better graphs. Recipe lines start with a tab, not spaces. .PHONY: clean.

What

Rebuild = outdated edge. The graph is the API: files are nodes, recipes are edge work.

Why

Compiles, codegen. Docker layers are the same “newer input → rerun” idea, hashed instead of mtime.

Trap

Missing a header in deps (stale .o). A recipe that never writes the target. Spaces instead of tabs.
