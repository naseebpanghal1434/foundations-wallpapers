LanguageMark from roots

Garbage is the unreachable.

Tracing GC reclaims objects with no path from roots: thread stacks, CPU registers, statics, JNI / global handles. Mark the graph, then sweep — age is irrelevant. A one-second object with no pointer is garbage; a ten-year Map entry is live. Mark-sweep (Java, JS) keeps cycles; naive refcount does not collect a.b = a.

WeakMap / WeakRef do not keep the key alive. A forgotten root is a leak.

What

Unreachable = garbage. Roots = frames (plate 69) + globals + the event loop. Mark-sweep handles cycles; Python adds a cycle detector on top of refcount.

Why

Heaps that only grow are a Map, a listener, or a closure — not “GC is broken.” Interviews: define reachability, name a leak, then a heap snapshot.

Trap

“JS has GC so it can’t leak.” Unbounded caches. Detached DOM still referenced from JS. A timer or subscription with no cleanup (plate 27).
