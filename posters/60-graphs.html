DSASparse vs dense

List the neighbors, or a matrix.

A graph is nodes plus edges. Two ways to store them. Adjacency list: each node holds the nodes it can reach. Adjacency matrix: a V×V grid, 1 if an edge exists. Directed: A→B is not B→A. Undirected: store both. Interview default is a list. A matrix on a sparse graph is how you OOM.

What

List: iterate neighbors in O(degree), edge-check O(degree). Matrix: edge-check O(1), iterate neighbors O(V). Weighted: store (to, w) on the list, or a number in the cell. Build from edge list in one pass.

Why

BFS/DFS (plate 59) walk neighbors — so the list is the API. Interviews: “how do you represent it?” then space. If they say undirected, you add both directions or you never come back.

Trap

A matrix on a sparse graph (the usual one). Forgetting the reverse edge on undirected. Using lists of lists with 1-based ids and a hole at 0. Storing an undirected edge twice in the input and twice again when you add both ways.
