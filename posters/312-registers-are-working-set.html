Arch~16 GPRs · spill

Registers are the working set. RAM is far.

x86-64: 16 GPRs (plus xmm/ymm). ARM64: 31. The compiler keeps live values in registers. Spill to stack when there are too many — stack is L1 (~1 ns) if you are lucky. A function with 40 live ints will spill. RAM is ~100 ns — about 100× L1, ~300 cycles at 3 GHz.

What

The true fastest memory is architectural registers. Everything else is a cache of RAM.

Why

Tiny hot loops beat fancy algorithms on tiny n. ABI matters: which regs are caller-saved.
