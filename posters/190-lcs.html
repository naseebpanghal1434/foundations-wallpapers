DSAdp[i][j] two strings

Match, or skip one side.

Longest common subsequence of s and t. dp[i][j] = LCS of s[:i] and t[:j]. If s[i-1]==t[j-1], 1+dp[i-1][j-1]; else max(skip s, skip t). O(n·m). Shortest common supersequence = n+m−LCS. Delete-distance to make equal = n+m−2·LCS. Print the string by walking the table back.

Substring is a different DPLongest common substring must be contiguous: consecutive matches, reset to 0 on mismatch. Space for LCS length: two rows (or rolling), not the full n×m, if you skip reconstruct.

not substring
What

Two-string DP. Subsequence keeps order, not adjacency. Empty vs empty is 0. Index the prefixes 1-based so row 0 / col 0 are the empty bases. Reconstruct stores choices or re-derives them from the numbers.

Why

LeetCode 1143. Diff tools, DNA, merge. Edit distance (plate 191) adds replace. Delete-only equal strings is n+m−2·LCS — say that when they forbid replace.

Trap

Substring DP (reset on mismatch) sold as LCS. Recursing without memo — exponential. Off-by-one empty prefixes (s[i] vs s[i-1]). Reconstructing without storing choices, then guessing the path.
