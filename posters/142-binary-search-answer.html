DSAMonotonic predicate

Binary search the answer, not the array.

The array may be unsorted. The answer is monotonic: “can we finish with capacity m?” flips from false to true once. Binary search m; check(m) is a linear scan. O(n log RANGE).

piles=[3,6,7,11] · h=8

lo, hi = 1, max(piles) mid=6 hours = ceil 1+1+2+2 = 6 ≤ 8 → try smaller ans = 4 ceil: (x + m - 1)//m # 11/4 = 2 (wrong) # (11+3)//4 = 3

lo lands on the first true. Init hi to max(piles) or sum, depending on the problem.

Monotone

can(m): F F F T T T ↑ first true can(m): F T F T flickers — cannot BS # trap: binary search # the piles — unsorted # trap: lo=mid with no # progress (plate 140)

If can(mid) is not monotonic, you cannot binary search it. Integer division is floor — ceil is (x+m-1)//m.

What

Search the solution space. A yes/no that flips once, plus a first-true loop (plate 140). check is usually O(n).

Why

Koko (LC 875), ship packages (1011), split-array largest sum (410). Say “monotonic in the guess,” then write the loop.

Trap

Binary searching the unsorted piles. Floor instead of ceil. lo=mid with no progress. A predicate that flickers.
