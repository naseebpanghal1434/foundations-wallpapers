OSnlink · unlink

The inode is the file. The name is a link.

Directory entry: name → inode number. Inode: type, mode, uid, size, timestamps, block map. nlink counts names. unlink removes a name; the inode and data live until nlink=0 and no fd. Hard link: two names, one inode, same filesystem. Symlink: a path string.

Identity

dev+ino

Paths are lookups, not identity.

What

Identity is the inode (device+ino). Paths are lookups. rename is atomic on one filesystem.

Why

Why deleting a log that is still open does not free disk. Why “same file” is st_dev+st_ino.

Trap

Assuming unlink deletes bytes immediately. Crossing devices with rename (EXDEV). Following symlinks in security checks (TOCTOU).
