OSsigaction · EINTR

A signal is an async interrupt to a process.

kill(pid, SIGTERM) sets a pending bit. At a safe point the kernel jumps to the handler (or default: terminate, core, ignore, stop). Only async-signal-safe functions in a handler (write, _exit — not malloc, printf); syscalls may return EINTR.

Why

Ctrl-C, timeouts (SIGALRM — prefer timerfd), child death (SIGCHLD). Graceful shutdown is SIGTERM then drain (plate 86).
