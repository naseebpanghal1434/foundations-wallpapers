FrontendReferential equality

memo loses if the object is new.

React.memo, useMemo, and useCallback skip work when refs are Object.is-equal to last time. Inline {} and () => {} are new every render, so the child memoizes nothing.

Context value={{user}} is a new object for every consumer (plate 238).

vs

stable refs · or don’t memo

Skip if Object.is

style = useMemo(…) onClick = useCallback(…, [id]) // or data-id + parent handler // (plate 230) primitive props are free

Wrap the value, or don’t memo — measure first. memo is “skip if the refs match,” not “make it fast.”

What

Shallow ref equality. Primitive props are free. memo is not “make it fast”; it is “skip if the refs match.”

Why

Premature memo is noise. Accidental new objects are why an “optimized” tree still renders.

Trap

memo everywhere. Spreading ...props so a new object always arrives. useMemo with empty deps on a value that should update.
