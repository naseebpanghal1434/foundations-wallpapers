Toolsptrace · -e trace=

strace prints the syscalls. That is the kernel API.

strace -p PID (or strace cmd) uses ptrace to log every syscall: name, args, return, errno, time. That is the process↔kernel interface (plate 287), independent of language. -e trace=file|network filters; the overhead is real — don’t leave it on in prod.

ltrace is libc. dtruss/ktrace on BSD. perf/ebpf for less tax.

What

A trace of traps. Arguments may be truncated pointers. Return = 0 or a fd is success; -1 ENOENT is not.

Why

First debugging tool on Linux: which path, which host, which errno — regardless of the language.

Trap

Reading errno as success. Following children (-f) on a thread storm. Treating the first failed open as the bug — a later one succeeded.
