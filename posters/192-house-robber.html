DSALinear DP · circle follow-up

Rob i, skip i-1. Or skip i.

Cannot rob adjacent houses. Linear: max(skip i, take i + skip i-1). Circle: max of two linears (drop first, or drop last). Tree: return a (rob, skip) pair.

Line of houses

Linear

[2, 7, 9, 3, 1] take i → skip i-1 skip i → keep dp[i-1] i=0 2 i=1 max(2, 7) = 7 i=2 max(7, 2+9) = 11 i=3 max(11, 7+3) = 11 i=4 max(11, 11+1) = 12 2+9+1 = 12 (not 7+3)

O(n) time, O(1) space. Same shape as fib / climbing stairs, with weights.

vs

First touches last

Circle

[2, 3, 2] cannot 2+2 max( linear drop last, [2,3] → 3 linear drop first, [3,2] → 3 ) = 3 n=1: return a[0] tree: pair per node rob = a[i] + skip L + skip R skip = max(rob,skip) L + max(rob,skip) R

Don’t run one DP on the circle. The split is the whole trick. Tree: return (rob, skip) so a parent cannot take a child twice.

What

Take i and skip i−1, or skip i. Linear: two scalars. Circle: max of two linears. Tree: a pair so a parent cannot also take a child.

Why

LeetCode 198 / 213 / 337. Follow-up is almost always the circle or the tree.

Trap

One DP on the circle (takes both ends). Tree: take a node and a child. Off-by-one on n=1.
