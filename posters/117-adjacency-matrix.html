An edge is a cell.

A matrix g[n][n] has g[u][v] = 1 (or weight) if the edge exists. Query is O(1). Memory is Θ(n²) whether the graph is empty or full. Walking neighbors of u scans a whole row — O(n), even if degree is 2.

Floyd–Warshall wants a matrix. BFS on a sparse graph does not. Image grids are a different beast (plate 118).

What

O(1) edge test, O(n) neighbor scan, Θ(n²) space. Weighted: store the weight, use ∞ for missing. Directed: not symmetric. You pay for every cell, including the zeros.

Why

n is tiny (≤400), or the algorithm is DP on i,j (Floyd, transitive closure). Some problems hand you the matrix already. A pixel grid is not this — plate 118.

Trap

n=10⁴ matrix: 10⁸ cells, often dead. Assuming undirected symmetry on a directed graph. Reusing g[u][u]=1 as a visited mark vs a self-loop — don’t overwrite the matrix as visited without a plan.
