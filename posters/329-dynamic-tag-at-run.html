10–100×
What

Values carry their operations. Open-world: new types at runtime. A static type (plate 328) erases this lookup from the hot path.

Why

Python feels fast for I/O (the kernel dominates) and slow for inner loops (this plate). A JIT (plate 323, 336) exists to hide the tag after types stabilize.

Trap

Microbenchmarking Python arithmetic against C and calling the language “slow” as if I/O were the same. Monkey-patching nb_add as architecture.
