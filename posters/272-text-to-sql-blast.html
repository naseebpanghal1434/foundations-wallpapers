GenAIRead-only · allowlist

Text-to-SQL has a blast radius.

A model that writes SQL is a user with your DBA’s vocabulary and a stranger’s intent. Allow SELECT on views, not DROP; parameterize (plate 16), cap rows, dry-run EXPLAIN (plate 98).

As DBA

execute(model.sql) role = admin on primary DROP TABLE … JOIN × JOIN

The schema you stuff is a leak and an injection surface (plate 46).

vs

LLM proposes · policy runs

Allowlist

allowlisted views parse AST reject writes timeout · row cap audit + replica

A tool (plate 47) on a read replica (plate 37). Never the primary with migrations.

What

Least privilege. Idempotent reads. The model does not get a connection string that can mutate.

Why

Internal copilots. The outage is one generated JOIN. Policy executes; the LLM only proposes.

Trap

Admin connection string. “The prompt says only SELECT.” Concatenating user text into the SQL the model already wrote.
